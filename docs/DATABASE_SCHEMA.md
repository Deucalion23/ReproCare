# ReproCare Database Schema Documentation

## Overview

**Database Name:** reprocare  
**Database Engine:** MariaDB 10.4.32  
**Character Set:** utf8mb4  
**Collation:** utf8mb4_unicode_ci  
**Total Tables:** 35 (excluding standalone system tables)  
**Normalization Status:** 100% (All tables normalized)

---
